DAFIM · Paquetes de facturas

Procesar un mes

Excel de paquetes + PDFs FEL (sueltos o en un ZIP).
Cada hoja del Excel es un paquete, con sus columnas de concepto y monto.
Selecciona todos los PDFs de una vez (Ctrl+A en la carpeta) o un unico ZIP con todos adentro. No importa el orden: el sistema los acomoda.
Volver

Como funciona

1. Se lee cada factura: numero de autorizacion, DTE, monto y descripcion. 2. Cada linea de cada paquete busca su factura por monto exacto y descripcion mas parecida. 3. Si dos facturas tienen la misma descripcion y monto, se usan una sola vez cada una: el numero de autorizacion nunca se repite, ni contra meses anteriores ya guardados. 4. Todo queda en la base de datos y puedes imprimir cada paquete como un solo PDF con las facturas en orden.
